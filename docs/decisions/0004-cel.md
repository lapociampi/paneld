## Context

One expression language for property bindings (`{{ ... }}`), alert mapping and conditions.

## Options

- **JSON paths with simple comparisons:** too weak for colors from thresholds, formatting, list filtering.
- **jq:** powerful, but a full language with loops and recursion; embedding it is heavy.
- **CEL (Common Expression Language):** typed, sandboxed, no loops, always terminates, compiled once and evaluated fast, clear errors; Rust implementation available (`cel-interpreter`).

## Decision

CEL. Complex reshaping of command output is done by `jq` inside the command, not by the program.

## Consequences

- Expressions are compiled and type-checked at config load: errors before anything is drawn.
- A few helper functions are added to CEL (rounding, formatting units and durations, theme lookups).
